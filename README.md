# HANSI Hotdog Haven

Build a complete, modern website for a fun Bahrain-based hotdog brand called HANSI.

1. Brand Direction

HANSI is a playful, casual hotdog brand built around good food, good buns, events, and good vibes.

The brand should feel:

Fun

Bold

Casual

Slightly cheeky

Social

Energetic

Nostalgic

A little retro, but not outdated

Use the HANSI logo I provided as the primary source for the visual identity. Analyze the logo and extract its:

Color palette

Typography style

Shapes

Visual personality

Graphic elements

Overall brand feeling

Build the website around those elements rather than introducing a completely different visual identity.

2. Overall Visual Style

Create a retro-inspired hotdog aesthetic with a modern website execution.

Think:

Classic American hotdog stands

Vintage diner graphics

Retro food posters

Playful typography

Sticker-style graphics

Simple illustrations

Wavy or curved shapes

Fun little visual surprises

Do not make it look like an old-fashioned restaurant website. It should feel like a contemporary food brand that happens to love retro design.

Use generous whitespace, strong typography, bold sections, and large food photography.

3. Tone of Voice

The copy should be casual, short, playful and confident.

Avoid corporate language.

Use phrases such as:

Bite Me!

Nice Bun!

Get Your Dog On.

Hot Dogs. Cool People.

Come Hungry. Leave Happy.

That’s One Good Dog.

Bun-believable.

Say hello to your new favorite dog.

Things are getting saucy.

No boring dogs here.

Use this style naturally throughout the website. Don't overuse catchphrases—each should feel like a little brand moment.

4. Website Structure

Create the following main navigation:

Home | Menu | Catering | Where We Are | About HANSI | Contact

Include a prominent CTA throughout the website:

GET HANSI FOR YOUR EVENT

HOME PAGE

The homepage should immediately communicate what HANSI is.

Hero Section

Large, visually exciting hero section featuring a delicious HANSI hotdog.

Headline:

BITE ME!

Supporting copy:

Good dogs. Nice buns. Big vibes.

CTA buttons:

GET HANSI FOR YOUR EVENT
SEE THE MENU

Add subtle animated elements such as:

A moving hotdog illustration

Sauce squiggles

Floating retro stickers

Slight text movement

Animated arrows

Keep animations smooth and tasteful.

Intro Section

Introduce HANSI in a short, fun way:

WE MAKE HOTDOGS.
YOU MAKE THE MEMORIES.

Explain that HANSI brings hotdogs to:

Events

Parties

Offices

Festivals

Private gatherings

Corporate events

Pop-ups

Basically anywhere people are hungry

CTA:

BRING THE DOGS →

"WHERE ARE WE?" SECTION

This should be one of the most important sections on the homepage.

Create a visually interesting section called:

WHERE'S HANSI?

or

CATCH US IF YOU CAN.

This section should show where HANSI is currently popping up around Bahrain.

Create an interactive/event-style display showing:

Event name

Date

Location

Event type

Short description

HANSI status

Example:

BAHRAIN FOOD FESTIVAL
📍 Bahrain
📅 12–15 March
🌭 Find us at the HANSI truck

Include a CTA:

SEE ALL EVENTS →

Design this section so it can easily be updated when new Bahrain events and festivals are added.

If possible, structure it as an event card carousel or interactive map-style experience.

Include a visual label such as:

HONK HONK. WE'RE HERE. 🌭

The design should make visitors want to check back regularly to see where HANSI is next.

MENU SECTION

Use the menu file/image I provided as the source of truth for the actual HANSI menu items.

Do not invent menu items that aren't included in the supplied menu.

Create an attractive menu layout with categories and large food imagery.

Each item should include:

Item name

Description

Price, if provided

Optional dietary/allergen information if provided

Use playful category titles where appropriate.

Example:

THE DOGS 🌭
SIDES 🍟
SAUCY STUFF 🌶️
DRINKS 🥤

But only use categories that make sense based on the supplied menu.

Add small playful copy around the menu:

Pick your dog. Add your sauce. Get messy.

CTA:

I'M HUNGRY →

CATERING PAGE

This page should focus heavily on HANSI's catering service.

Headline:

YOU BRING THE PEOPLE.
WE'LL BRING THE DOGS.

Explain that HANSI caters for:

Birthday parties

Corporate events

Office lunches

Private parties

Weddings

Festivals

Brand activations

School/university events

Pop-ups

Community events

Any gathering where hungry people exist

Create different catering options/packages based on the information available, but do not invent pricing or package details.

Include an enquiry form with:

Name

Company / Organization

Email

Phone

Event type

Event date

Event location

Number of guests

Message / requirements

CTA:

LET'S GET THIS PARTY STARTED

Make the form feel friendly rather than corporate.

ABOUT HANSI

Create a short brand story.

The tone should be:

We love hotdogs.
We love feeding people.
We love a good party.
So we put all three together.

Keep this section visually driven and concise.

Use playful illustrations and photography rather than a long wall of text.

Potential headline:

WHO LET THE DOGS OUT?
WE DID.

CONTACT

Create a simple contact section for:

General enquiries

Catering enquiries

Event bookings

Partnerships

Collaborations

Make the primary CTA:

TALK TO HANSI

Include social media links and encourage users to follow HANSI for upcoming locations and events.

ANIMATIONS & INTERACTIONS

Use animation strategically.

The website should feel alive, but not overloaded.

Ideas:

Hotdog follows the cursor subtly

Sauce squiggles animate into sections

Buttons have playful hover effects

Menu cards slightly tilt or bounce on hover

"Bite Me!" text has a subtle movement

Event cards slide horizontally

Scroll-triggered illustrations

Retro stickers pop into view

Small animated arrows pointing toward CTAs

A hotdog loading animation

Use smooth transitions and modern animation principles.

Animations should support the brand and usability rather than distract from the content.

MOBILE EXPERIENCE

The website must be designed mobile-first.

Most visitors will likely discover HANSI through Instagram, events, or mobile browsing.

On mobile:

Keep navigation simple

Make CTA buttons large

Make the menu easy to browse

Make event information highly visible

Make the catering enquiry form easy to complete

Optimize images for fast loading

Keep animations lightweight

Consider a persistent mobile CTA:

GET HANSI →

DESIGN DETAILS

Use the colors extracted from the supplied HANSI logo as the primary brand palette.

Use complementary neutral colors where necessary.

Typography should feel bold, playful and highly readable.

Use a combination of:

Strong display typography for headlines

Clean typography for body copy

Occasional retro/handwritten styling for small brand moments

Use graphic elements inspired by:

Hotdog illustrations

Mustard/ketchup lines

Retro badges

Stars

Checkered patterns

Stickers

Arrows

Diner-style shapes

Use these sparingly so the website doesn't become visually cluttered.

PHOTOGRAPHY

Food photography should be appetizing, close-up, colorful and energetic.

Focus on:

Hotdogs

Buns

Sauces

Toppings

Hands grabbing food

People enjoying HANSI

Events

HANSI setup

Crowd moments

Photography should feel candid and social rather than overly polished or generic stock photography.

BRAND EXPERIENCE

The most important feeling when someone visits the website should be:

"This looks fun. I want a HANSI."

The website should feel like an extension of the HANSI food experience—not simply a restaurant website.

Every section should have personality.

Use short, punchy copy instead of long explanations.

Examples of microcopy:

NICE BUN.
MORE SAUCE? ALWAYS.
CURRENTLY GETTING GRILLED.
GOOD DOGS ONLY.
NO BORING BITES.
OH, THAT'S SAUCY.
SEE YOU AT THE NEXT PARTY.

IMPORTANT CONTENT RULES

Use the supplied HANSI logo to establish the visual identity.

Use the supplied menu as the source of truth for menu items.

Do not invent menu items or prices.

Make the Bahrain events/location section easy to update.

Design the site so HANSI can continuously add upcoming events and festivals.

Prioritize catering conversions.

Make "Get HANSI for your event" one of the strongest CTAs on the website.

Keep the language fun, casual and confident.

Avoid generic restaurant clichés and corporate wording.

The final website should look like a real, launch-ready food brand, not a generic website template.
